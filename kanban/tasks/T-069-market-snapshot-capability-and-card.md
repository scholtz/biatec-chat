# T-069 · market.snapshot capability and market card from Biatec DEX data

## Context

Read `docs/design/README.md` (mapping and status table), `docs/design/biatec-ai-widget/README.md` (pixel spec), `packages/chat-widget/AGENTS.md` (UI rules); prototype screen 6, MarketInsightCard.

Spec, User Experience 10: "A market snapshot card (price, 24 h change with arrow and sign, high, low, volume, sparkline, timestamp) is planned for public Biatec DEX data and needs its own anonymous capability first."

Biatec DEX exposes public market data through its API (see `src/api` in `scholtz/BiatecDEX`, generated by orval: asset stats, OHLC history, aggregated pools). Public facts are allowed in the anonymous tier ("no price-sensitive advice beyond public facts").

## Goal

Visitors and users can ask about an Algorand asset or a Biatec DEX pair and get a factual market card built from Biatec DEX data.

## Scope

- In: capability `market.snapshot` (tier Anonymous, no scopes, does not move funds) in the capability registry, backed by the Biatec DEX public API (base URL in configuration), with a short cache; returns a `data_card` of kind `market` (`pair, price, change24hPct, high24h, low24h, volume24h, series[], asOf, source`).
- In: widget `MarketCard`: kicker "Market snapshot · Biatec DEX", price 26/600 tabular, change with ▲/▼ + sign + colour (past only), 96 px sparkline (line in text colour, no green/red fill), 3-column stats, stamp "Snapshot HH:MM UTC · not live".
- In: update the capability table in PRODUCT-DESCRIPTION.md.
- Out: forecasts, signals or recommendations; live streaming prices.

## Parallel work

Parallel work possible: **yes**. No other unfinished task that could run at the same time changes the same files.

## Acceptance criteria

- [ ] Tier policy test: `market.snapshot` is available to anonymous sessions and is the only new anonymous tool
- [ ] Backend test with a mocked Biatec DEX API returns the event with decimal strings and the timestamp of the data, not of the request
- [ ] Widget test renders up and down fixtures with arrow, sign and word, and never animates the price
- [ ] An upstream failure yields a plain-text "market data unavailable" answer, no card

## Implementation notes

- The model may describe the card but must not invent numbers; the card is the source.
- Respect the hackathon rule: no new AWS resources needed.
