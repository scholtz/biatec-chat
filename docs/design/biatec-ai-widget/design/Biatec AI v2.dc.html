Components
BiatecAIWidget ├ ChatLauncher └ ChatPanel ├ ChatHeader · AutonomySelector ├ ChatMessages → AIResponse │ ├ MarketInsightCard │ ├ TradeProposalCard │ └ RiskSummary ├ ChatComposer ├ PermissionDialog └ ActivityTimeline
Isolation & theming
Renders inside Shadow DOM so host CSS can't leak in or out. Hosts override CSS custom properties only: --color-*, --font-*, --radius-*, --space-*, --shadow-*. Signing stays in the host's wallet flow. The widget never receives keys, seed phrases or API secrets; permissions are enforced server-side.
Try it: switch Host theme or Embed mode in Tweaks.
