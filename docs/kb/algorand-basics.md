# Algorand basics

Algorand is a proof-of-stake blockchain with fast finality, usually a few seconds per block, and low transaction fees. The native coin is ALGO. Other tokens are Algorand Standard Assets (ASAs) such as USDC and EURS.

An account must opt in to an asset before it can receive it. Opting in is a zero-amount transfer of that asset to yourself. An account also needs a minimum ALGO balance, which grows with each opt-in and each application it uses.

Transactions are sent as groups that succeed or fail together. A signed group is only valid for a limited number of rounds (at most 1000, about 45 minutes), so a preview expires if it is not confirmed in time.
