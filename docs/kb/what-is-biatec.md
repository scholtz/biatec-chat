# What is Biatec

Biatec is a family of self-custody finance products built on Algorand. The products are Biatec OIDC (sign in with Google or Microsoft and get a self-custody wallet), Biatec MCP (wallet tools for AI assistants), Biatec DEX (a concentrated-liquidity exchange), Algo Safe (shared smart accounts with approvals) and Biatec Web (the product site).

Keys stay with the user. Biatec OIDC derives Algorand, EVM and Bitcoin keys and stores them encrypted in the user's own cloud storage. Third-party apps can ask for signing only under spending limits the user controls.

Biatec Chat is the assistant on Biatec pages. Anyone can ask it what Biatec offers. Signed-in users can also prepare actions such as transfers, swaps and liquidity, and every action shows a preview before anything is signed.
